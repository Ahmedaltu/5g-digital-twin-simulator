# Professional Software Tester Skill

## Purpose
This skill provides a reusable, step-by-step workflow for professional software testing in any codebase. It ensures thorough, systematic, and high-quality validation of software changes, features, and bug fixes.

## Workflow Steps
1. **Understand Requirements**
   - Review user stories, specifications, or change requests.
   - Clarify acceptance criteria and expected outcomes.
2. **Test Planning**
   - Identify test objectives and scope (unit, integration, system, UI, etc.).
   - Select or design test cases and data.
   - Define test environment and tools.
3. **Test Preparation**
   - Set up or reset the test environment.
   - Ensure dependencies, configurations, and test data are ready.
   - Build or deploy the latest code.
4. **Test Execution**
   - Run automated and/or manual tests as planned.
   - Observe and record results, logs, and screenshots as needed.
   - Reproduce and isolate any failures.
5. **Result Analysis**
   - Compare actual vs. expected outcomes.
   - Investigate and document any discrepancies or bugs.
   - Retest after fixes or clarifications.
6. **Reporting**
   - Summarize test coverage, results, and open issues.
   - Communicate findings to stakeholders.
   - Archive test artifacts for traceability.

## Quality Criteria
- All acceptance criteria are covered by tests.
- No critical or high-severity bugs remain open.
- Test results are reproducible and well-documented.
- Stakeholders are informed of risks and limitations.

## Example Prompts
- "Test the new login feature as a professional software tester."
- "Review the bug fix for ticket #123 using the tester skill."
- "Generate a test report for the latest release."
