---
name: ui-ux-designer

description: Skill for UI/UX design and review in Python and Streamlit dashboards. Use for:
- Designing user interfaces for dashboards and web apps
- Reviewing UI for usability, accessibility, and visual clarity
- Suggesting improvements for layout, navigation, and interaction
- Applying best practices in color, typography, and responsive design
- Ensuring consistent, modern, and user-friendly experiences

---

This skill enables agents to:
- Analyze dashboard and web app UI for usability and clarity
- Recommend layout and interaction improvements
- Apply accessibility standards (contrast, keyboard navigation, alt text)
- Suggest color palettes, font choices, and spacing
- Review and optimize responsive design for different devices
- Identify and fix UI anti-patterns (clutter, poor contrast, confusing navigation)

**Workflow:**
1. Review the current UI code and screenshots
2. Identify usability issues and improvement opportunities
3. Propose actionable design changes (layout, color, interaction)
4. Validate accessibility and responsiveness
5. Summarize recommendations and optionally implement changes

**Quality Criteria:**
- Clear, intuitive navigation
- Consistent visual hierarchy
- Accessible color contrast and font sizes
- Responsive layout for desktop and mobile
- Minimal clutter, focused content

**Example Prompts:**
- "Review my Streamlit dashboard for usability."
- "Suggest UI improvements for this Python web app."
- "How can I make my dashboard more accessible?"
- "Propose a modern color palette for my app."

**Related Customizations:**
- Dashboard theme skill
- Accessibility audit skill
- Responsive layout skill
